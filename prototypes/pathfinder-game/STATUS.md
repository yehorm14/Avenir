# Status: standalone prototype, not an Avenir slice

This folder is a **self-contained prototype** ("Pathfinder", a game-styled careers app) built separately from the Avenir
slices. It touches no slice folder, no contract and no shared doc. It is here so the team can see it, run it, and lift
ideas from it. **It is not meant to be merged wholesale into `main`.**

## Run it

Python 3.12 and Node 22 (see the conda line in `README.md`), then `./run.sh` and open http://localhost:8000.
Tests: `cd backend && python -m pytest -q` (32 tests).

## How it differs from AGENTS.md (read before reusing anything)

| AGENTS.md rule | State in this prototype |
| --- | --- |
| 2. Provenance on every number | Partly. Score components carry a `source_id`, but not the full `{value, low, high, source, year, region, granularity, n, confidence}` envelope. |
| 3/4. Missing means missing; never invent values or URLs | Missing data is shown as "No data" and never filled in. **But the snapshot values are illustrative**, and the pay history (`backend/data/snapshots/ashe_series.json`) and backtest (`backtest.json`) are **synthetic**, generated by `backend/scripts/build_demo_snapshots.py`. The app labels both. CPI (`cpi.json`) is approximate and written from memory. **Everything in `backend/data/` is `(verify)`.** |
| 4. URLs | The opportunities, universities, societies and competitions in `backend/data/` are curated from memory. Links go to organisers' homepages and none have been checked: **all `(verify)`**. No dated events are included, only typical timing windows. |
| 5. Adapters / snapshots | Same idea (adapter per source with a snapshot fallback, `backend/app/adapters/`), but the snapshots are hand-written or generated, not fetched. |
| 6. Backtest honesty | The engine has a no-look-ahead test, but runs on synthetic data, so its results mean nothing yet. |
| 7. Wording for a 17-year-old | Uses "AI exposure" and "AI resilience", not "Automation exposure (research estimate)". Pay verdicts ("Beat inflation", "Fell behind") would need a wording review. |
| 9. Forbidden sources | None used. Nothing is scraped. Licences of the listed sources have not been checked. |
| 1. No LLM in ranking | Met. Scoring is deterministic (`backend/app/scoring.py`); an optional LLM only explains, behind a validator. |

## Ideas worth lifting

- **Path planner**: degrees, example universities, hard and soft skills, societies, competitions, alumni message kit, year-by-year plan.
- **Safe path**: counts how many careers each degree keeps open, and suggests the broader degree when it opens more.
- **Radar**: opportunities by field, stage and nation, with a digest. Understands exact `opens` and `deadline` dates once a live feed supplies them.
- **Pay and inflation**: pay by year in today's money, with the spread, and an inflation calculator.
- **Events**: stress-test scenarios scored for a pick and its backup, with an effort slider.
- **Character and arcade**: a game layer, with XP earned only from real-world evidence, and a "call the year" backtest game.
- **Trust docs**: `docs/scoring-spec.md` and `docs/childrens-code-assessment.md`.
