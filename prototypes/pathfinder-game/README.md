# Pathfinder backend (legacy module)

The earlier Pathfinder prototype's Python backend. `apps/web/api` imports its
`app.data` and `app.path` modules to build career pathways, so it stays in the
tree. The prototype's frontend and demo scripts were removed.

Tests: `PYTHONPATH=prototypes/pathfinder-game/backend python -m pytest prototypes/pathfinder-game/backend/tests`

Figures under `backend/data/snapshots/` are illustrative placeholders; the
backtest series is synthetic, generated by `backend/scripts/build_demo_snapshots.py`.
