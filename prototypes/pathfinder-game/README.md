# Pathfinder

**GUTS Hackathon · Aladdin by BlackRock: "One app. One clear decision."**

Before you commit years to a career, Pathfinder gives you the analysis an investor would expect before committing money:

- fit
- pay
- demand
- AI exposure
- confidence
- a hedge career
- a stress test
- a next step

Unlike other careers tools, **it publishes its own track record**. This is the "Pathfinder Full" plan from `message.txt`, built on top of the original Ellie spec in `project-idea-summary.md`.

> ⚠️ **Demo data.** Every figure in `backend/data/snapshots/` is an illustrative placeholder in the real shape of its source. The backtest series is **synthetic**, generated by `backend/scripts/build_demo_snapshots.py`. The app says so on every page. Load the real sources, and have a person check every row, before anyone relies on it.

## Run it

```bash
./run.sh
```

Then open http://localhost:8000. The script builds the frontend if it needs to, then serves the app and the API from one process. Interactive API docs are at `/docs`.

The project uses a local environment in `.conda/` (Python 3.12, Node 22). To recreate it:

```bash
conda create -p ./.conda -c conda-forge python=3.12 nodejs=22 fastapi uvicorn pydantic pytest httpx
```

**Development mode** (hot reload), in two terminals:

```bash
.conda/bin/python -m uvicorn app.main:app --app-dir backend --reload --port 8000
cd frontend && PATH=../.conda/bin:$PATH npm run dev     # http://localhost:5173
```

**Tests:** `cd backend && ../.conda/bin/python -m pytest -q` (32 tests: safeguards, path data, events, the arcade, the radar, safe paths and pay maths).

## The game

The whole app is a game skin over the real analysis. Nothing in the ranking changed, and every number is still sourced.

| Game idea | What it is underneath |
| --- | --- |
| **Create your character** | A 30-question quiz (5 per interest type), shown one card at a time. The avatar and a six-stat hexagon update live after every answer. |
| **Class** | Your top two interest traits as a hybrid, for example "Scholar-guide". A label for your interests today, not a verdict; you can respec any time. |
| **Stats** | The six interest traits (Build, Think, Create, Help, Lead, Organise). |
| **Gear up** | Region, school subjects and experience, which feed the head-start score. |
| **Meet your party** | Your three picks, each with a backup career. |
| **Quest map** | The path planner. Its steps are tickable quests, drawn as a map with progress rings. |
| **Guilds, boss battles, mentors** | Societies, competitions and the alumni message kit. |
| **Events** | The stress-test scenarios. Split your effort between your pick and its backup, and see the party's worst case. Scores come from the same formula, and the app says it is a game score, not a forecast. |
| **Arcade: Call the year** | Pick the 3 of 10 past careers you think grew most over four years, then compare with the algorithm and with hindsight. Rounds are deterministic by year and seed, and outcomes are hidden until you lock in. Currently on the synthetic backtest series. |
| **Level and XP** | 10 XP for each skill or quest step you tick. **XP comes only from real-world evidence you tick, never from time spent in the app.** |

By design there are no streaks, countdowns, daily rewards or leaderboards (see `docs/childrens-code-assessment.md`). Progress is kept on the device and wiped by "Clear my data".

## Pay and inflation

`/#/pay` (API: `GET /api/pay`, `GET /api/inflation`) answers "is my pay really holding its value?". £50,000 ten years ago and £50,000 now is not stability: prices rose, so the same number buys less.

- **Is it still the same money?** A calculator: "In 2015 you earned £50,000" gives "£50,000 in 2015 buys what £69,250 does in 2025. If you still earn £50,000, it's worth 28% less than it was."
- **Pay over time:** median pay each year for up to four careers, with the middle half of full-time employees (25th to 75th percentile) shaded as the spread. Switch between **today's money** (CPI-adjusted to 2025 prices, with the unadjusted line dashed so you can see the gap inflation opened) and **money of the day** (as it appeared on payslips). Hover, tap or use the arrow keys to read any year; a table of every number sits underneath.
- **The verdict, career by career:** *Beat inflation*, *Kept pace* or *Fell behind* (within ±3% real change counts as keeping pace), the same pay in then-money and now-money, and whether the spread has widened or narrowed.
- **Median, not average**, because a few very high earners pull an average up. Careers where ONS publishes no pay figure show "No data" and no series is made up.
- It starts on your party's careers, and is reachable from "Over time, real terms" on each party member and career page.

**What is real and what is not (important):**

- **Inflation:** `data/snapshots/cpi.json` holds **approximate** UK CPI annual averages (2015 = 100), written from the published annual rates. Replace them with ONS series D7BT and check every year.
- **Pay history:** `data/snapshots/ashe_series.json` is **SYNTHETIC**. The 2024 and 2025 points come from `ashe.json` (itself demo), and 2015 to 2023 are generated backwards by `scripts/build_demo_snapshots.py` with a seeded growth path. The page says so in a banner. It shows how the dashboard works, **not what pay really did**. Load ASHE Table 14 by SOC 2020 (with the SOC 2010 bridge for earlier years) and have a person check it before relying on it.
- The maths is tested: converting an amount there and back returns the same money, and in the base year real equals nominal.

## Radar: opportunities in your fields

`/#/radar` (API: `GET /api/radar`) answers "I know what I want to try, but where?". It opens on the fields of your party and lists programmes, open days, hackathons, work experience, competitions and communities for them, **including many for people not yet at university**.

- **Filters:** your fields (add or remove), your stage (school, college, university) and your nation. Nation-specific items (for example apprenticeship portals) appear only for the right nation.
- **Today's digest:** how many are in their usual opening window now, how many open next month, and how many are open all year, with three highlights. It is rebuilt every time you open the Radar, so it changes as the calendar does, and it flags what is new since your last visit.
- **"I've done this":** tick an opportunity you've really done to earn XP, like any other evidence.
- **Trend check:** for hot fields (quantum, AI, cyber security, clean energy, biotechnology), the specialist route against a broader degree that gets you there while keeping more doors open. The doors are counted from our own careers data.

**Safe path:** on each quest map, if a broader degree opens more careers than the most direct one, a card says so and how to specialise later without closing doors. For cyber security: Cyber security opens 1 career in our list, Computer science opens 3. For investment analyst: Finance opens 1, Business and management opens 4. Doors are a guide to flexibility, not a prediction.

**What is real and what is not (important):**

- The opportunities in `backend/data/snapshots/opportunities.json` are **real organisers and programme types** (for example NCSC CyberFirst, Nuffield Research Placements, Arkwright Scholarships, Astro Pi, Forage, WorldSkills UK). They carry **no invented dates**: each has the months it *typically* opens, or "open all year". Links go to the organiser's homepage. A person must verify each entry before real use.
- **Employer-specific, dated events** (a particular company's open day) need a live feed, and **no live feed is connected yet**. The `opportunity_feeds` adapter is the slot for it, and the radar already understands exact `opens` and `deadline` dates: when a feed supplies them, expired items drop out, and "closing soon" appears.
- **No daily push.** The app has no accounts and stores nothing on a server, so it cannot message anyone. The digest refreshes when the Radar is opened. An opt-in email or notification digest would need consent handling first (see `docs/childrens-code-assessment.md`).
- The trend "heat" labels are a curated qualitative note, not a measurement. Real job-advert demand data (for example Lightcast) is not connected.

To add a live source: implement `fetch_live()` in `OpportunitiesAdapter` (in `backend/app/adapters/__init__.py`), returning the same JSON shape with optional `opens` and `deadline` ISO dates, and set `CAREERS_LIVE=1`. The snapshot stays as the fallback if the feed is down.

## The path planner

Each pick opens a **path** (`/#/path/<SOC>`, API: `GET /api/path/{soc}?nation=`). It turns "which career" into "what do I do next", and puts skills ahead of the degree.

| Section | What it gives you |
| --- | --- |
| **How much the degree matters** | An honest label: *required* (nursing, vet, teaching, social work, clinical psychology), *the usual route* (engineering, law-adjacent, science), *skills matter more* (finance, digital, business, design) or *optional* (trades, care, IT support, chef, police), with the reason. |
| **Routes** | **University** and **Apprenticeship and college**, side by side, defaulting to the one that fits the career. Routes come for England, Scotland, Wales and NI. |
| **Choose a degree** | Every degree subject that leads to the career (for investment analyst: Finance, Economics, Business and management, Accounting and finance, Mathematics), with what it teaches, what it builds, and who it suits. |
| **Where to study** | Example universities per degree, with your nation first (switch to all UK), plus UCAS, Discover Uni and the right student-funding agency for where you live. |
| **Skills matter more than the degree** | 4 hard and 4 soft skills per career, each with how to build it, and what evidence to show. Tick them as you start; progress stays on your device. |
| **Societies and competitions** | Society types to join and competitions to enter, each tagged with the skills it builds, and **real experience** (internships, placements, volunteering) with timing. |
| **Talk to people who've done it** | How to find alumni, who to look for, questions to ask, and a ready-to-edit message you can copy. |
| **Plan, step by step** | A year-by-year timeline for the university route, or an application-to-qualified timeline for apprenticeships. |

Data lives in `backend/data/pathways/` (`subjects.json`: 37 degree subjects with example institutions; `families.json`: 20 career groups; `common.json`: soft skills, alumni kit, apprenticeship finders and funding links). **It is curated demo content.** Institutions are examples of places known for each subject, not a ranking, and society and competition names are examples that change every year. Tests check that every career has a complete plan and every course subject has detail, but a person must verify the content before real use.

## How the score works

The full specification for reviewers is in `docs/scoring-spec.md`. In short:

`score = 100 × Σ wᵢ·sᵢ` over the signals that have data, with weights renormalised over those signals.

| Signal | Default weight | Source |
| --- | --- | --- |
| Interest fit (Pearson correlation of RIASEC profiles) | 30% | O*NET |
| UK need by 2035 (projected growth × regional multiplier) | 20% | Skills England |
| UK need now (skill-shortage density × regional multiplier) | 15% | Employer Skills Survey |
| Pay (median, full-time) | 15% | ASHE |
| AI resilience (1 − task-level exposure) | 10% | ILO WP140 |
| Head start (your subjects and experience) | 10% | Curated mapping |

**Safeguards** (all tested):

- Interest fit below 0.5 is never shown, whatever the weights.
- Missing data shows as "No data" and is never filled in.
- If every answer is the same, nothing is shown.
- AI never ranks. The optional LLM explainer (`CAREERS_LLM_URL`, any OpenAI-compatible server, for example vLLM on our own 8 × A6000) is checked by a validator, and the app falls back to templates without it.

## Architecture

```
frontend/              React + TypeScript (Vite). Apple-style, light and dark mode, works on phones, prints
backend/app/
  main.py              FastAPI. Contract exported to openapi.json
  models.py            Pydantic models = the API contract
  scoring.py           Six-signal score, regional lens, stress test, hedge, confidence
  radar.py             Opportunities digest and trend check
  pay.py               Pay over time: nominal against CPI-adjusted, spread, inflation calculator
  path.py              Path planner and safe path: degrees, universities, skills, societies, alumni kit, timelines
  backtest.py          Self-grade: as-of signal rebuild, metrics, replay, per-career track
  explain.py           Evidence builder, optional LLM, validator, template fallback
  discover.py          Free-text matcher and its held-out evaluation
  trust.py             Runs the AI evaluation set
  adapters/            One adapter per source, live fetch with snapshot fallback
backend/data/
  occupations.json     40 occupations (SOC 2020)
  quiz.json            30 quiz items (5 per interest type)
  ai_eval.json         AI evaluation set
  discovery_eval.json  Held-out discovery examples
  pathways/            Degrees, universities, skills, societies, competitions, alumni kit, trend specialisms (curated demo)
  snapshots/           One file per source (demo)
backend/scripts/build_demo_snapshots.py   Generates the regions, nations and (synthetic) backtest snapshots
docs/                  Scoring spec and Children's Code assessment
```
